# Department Employee Management System

A simple C# Console Application that manages department information and displays a list of employees using **classes, objects, properties, constructors, `List<T>`, and `foreach`.

## Features

* Store multiple employee records
* Store employee ID, name, and position
* Create a department with an employee list
* Display department information
* Display employees in a formatted table
* Use `List<Employee>` to manage multiple employees
* Use `foreach` to display employee records
* Use console colors for presentation

## Concepts Used

* Classes & Objects — `Employee` and `Department` represent application data.
* Properties — Stores employee and department information.
* Constructors — Initializes employee and department objects.
* List<T> — Stores multiple employee objects.
* foreach — Iterates through and displays employees.
* Object Composition — `Department` contains a list of `Employee` objects.
* String Formatting — Creates a structured employee table.
* Console Colors — Improves console presentation.
